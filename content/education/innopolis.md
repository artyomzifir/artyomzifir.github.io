## en

Specialization in robotics and machine learning. Active in research since year 1.

### course_data_hard
Introduction to Computer Vision :: Classical CV foundations through deep learning: image filtering, binary vision, feature extraction, Hough transform, stereo vision, object detection, GANs, semantic segmentation, video tracking. Python + OpenCV. Grade: A.
Applied ML & DL :: Full ML pipeline: CNNs, RNNs, transformers, generative models. PyTorch-based practicals including training loops, experiment tracking, and deployment basics. Grade: A.
Autonomous Mobile Robotics :: Bug algorithms, A* planning, SLAM, RTAB-Map, stereo odometry. All assignments implemented in ROS2 with Gazebo. Grade: A.
Sensors & Systems :: Sensor physics and signal processing, calibration, filtering (Kalman, median), sensor fusion for robotics. Practical work in Python/Colab. Grade: A.
Control Theory :: PID, state-space models, stability analysis, LQR. Applied to physical systems including inverted pendulum. Grade: A.
Advanced C/C++ — VK :: Modern C++ mechanisms, performance-oriented design, Docker + gtest. Summer 2024. Grade: A.

### course_data_soft
Technical Communication :: Docs-as-code, audience analysis, API references, iterative write→review→revise cycle. Hugo SSG, Writerside IDE. Instructor: Katerina Ushakova. Summer 2025. Grade: A.
Advanced Technical Communication :: Advanced docs-as-code, DocOps, CI/CD for docs, Sphinx + Doxygen, AI-assisted writing, documentation quality assurance and distribution. Based on real project (Total Control). Instructor: Katerina Ushakova. Spring 2026. Grade: A.
Product Solution Engineering (PSE) :: Product lifecycle, roadmaps, backlog management, metrics, hypothesis-driven development, go-to-market. Instructor: Marat Gadzhimuradov (Lead PM, Krasnoyarsk Non-Ferrous Metals Plant). Summer 2025. Grade: A.

## ru

Специализация — робототехника и машинное обучение. Активно занимаюсь исследованиями с первого курса.

### course_data_hard
Введение в компьютерное зрение :: Классическое CV до глубокого обучения: фильтрация, бинарное зрение, признаки, преобразование Хафа, стерео зрение, детекция объектов, GAN, семантическая сегментация, трекинг. Python + OpenCV. Оценка: A.
Прикладное МО и глубокое обучение :: Полный ML-пайплайн: CNN, RNN, трансформеры, генеративные модели. Практика на PyTorch: циклы обучения, трекинг экспериментов, основы деплоя. Оценка: A.
Автономные мобильные роботы :: Bug-алгоритмы, A*, SLAM, RTAB-Map, стерео одометрия. Все задания в ROS2 с Gazebo. Оценка: A.
Сенсоры и системы :: Физика датчиков и обработка сигналов, калибровка, фильтрация (Калман, медианный), слияние данных для робототехники. Практика в Python/Colab. Оценка: A.
Теория управления :: PID, пространство состояний, анализ устойчивости, LQR. Применение к физическим системам. Оценка: A.
Продвинутый C/C++ — VK :: Современные механизмы C++, производительное проектирование, Docker + gtest. Лето 2024. Оценка: A.

### course_data_soft
Техническая коммуникация :: Docs-as-code, анализ аудитории, API-референсы, итеративный цикл писать→ревьюить→переписывать. Hugo SSG, Writerside IDE. Преподаватель: Катерина Ушакова. Лето 2025. Оценка: A.
Продвинутая техническая коммуникация :: Продвинутый docs-as-code, DocOps, CI/CD для документации, Sphinx + Doxygen, ИИ в техписательстве, контроль качества и дистрибуция. На базе реального проекта (Total Control). Преподаватель: Катерина Ушакова. Весна 2026. Оценка: A.
Инженерия продуктовых решений (PSE) :: Жизненный цикл продукта, дорожные карты, бэклог, метрики, гипотезы, выход на рынок. Преподаватель: Марат Гаджимурадов (Lead PM, Красцветмет). Лето 2025. Оценка: A.
