Специализация — робототехника и машинное обучение. Активно занимаюсь исследованиями с первого курса.

## course_data_hard
Введение в компьютерное зрение :: Классическое CV до глубокого обучения: фильтрация, бинарное зрение, признаки, преобразование Хафа, стерео зрение, детекция объектов, GAN, семантическая сегментация, трекинг. Python + OpenCV. Оценка: A.
Прикладное МО и глубокое обучение :: Полный ML-пайплайн: CNN, RNN, трансформеры, генеративные модели. Практика на PyTorch: циклы обучения, трекинг экспериментов, основы деплоя. Оценка: A.
Робототехника и ROS2 :: Архитектура ROS2, навигационный стек, SLAM, слияние данных сенсоров, манипуляция. Практика на реальных и симулированных роботах. Оценка: A.
Автономные мобильные роботы :: Bug-алгоритмы, A*, SLAM, RTAB-Map, стерео одометрия. Все задания в ROS2 с Gazebo. Оценка: A.
Сенсоры и системы :: Физика датчиков и обработка сигналов, калибровка, фильтрация (Калман, медианный), слияние данных для робототехники. Практика в Python/Colab. Оценка: A.
Теория управления :: PID, пространство состояний, анализ устойчивости, LQR. Применение к физическим системам. Оценка: A.
Алгоритмы и СД :: Анализ сложности, графы, динамическое программирование, продвинутые структуры данных. Оценка: A.
Linux и DevOps :: Внутренности Linux, shell-скрипты, Docker, CI/CD, Git-воркфлоу. Оценка: A.
Продвинутый C/C++ — VK :: Современные механизмы C++, производительное проектирование, Docker + gtest. Лето 2024. Оценка: A.

## course_data_soft
Техническая коммуникация :: Docs-as-code, анализ аудитории, API-референсы, итеративный цикл писать→ревьюить→переписывать. Hugo SSG, Writerside IDE. Преподаватель: Катерина Ушакова. Лето 2025. Оценка: A.
Продвинутая техническая коммуникация :: Продвинутый docs-as-code, DocOps, CI/CD для документации, Sphinx + Doxygen, ИИ в техписательстве, контроль качества и дистрибуция. На базе реального проекта (Total Control). Преподаватель: Катерина Ушакова. Весна 2026. Оценка: A.
Инженерия продуктовых решений (PSE) :: Жизненный цикл продукта, дорожные карты, бэклог, метрики, гипотезы, выход на рынок. Преподаватель: Марат Гаджимурадов (Lead PM, Красцветмет). Лето 2025. Оценка: A.
